### Задача: Longest Substring Without Repeating Characters.

Дано:
```
s = "abcabcbb"
```
Нужно вернуть длину самой длинной подстроки без повторяющихся символов:
```
3
```

Ограничения:
```
1 <= len(s) <= 100000
```
Требования:

- O(n) по времени;
- O(n) по памяти допустимо;

напиши функцию:
```
func lengthOfLongestSubstring(s string) int
```
