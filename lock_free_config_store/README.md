Требования:

- Get() вызывается миллионы раз в секунду из разных goroutine.
- После успешного Load() все последующие Get() должны видеть полностью опубликованный Config.
- Get() не должен брать mutex.
- Load() может вызываться конкурентно несколькими goroutine, но loader() должен выполниться не более одного раза одновременно.
- Если loader() вернул ошибку, конфигурация не должна измениться.
- Если loader() сделал panic, состояние store должно остаться валидным.
- Нельзя использовать sync.Once.
- Нельзя использовать atomic.Value.
- Можно использовать atomic.Pointer, sync.Mutex и context, если понадобится.
