Требования:

load() может быть очень медленным — нельзя держать глобальный Lock во время load().
Если одновременно 100 горутин запросят один отсутствующий ключ, load() должен выполниться ровно один раз.
Горутины, ожидающие этот ключ, должны получить тот же результат.
Для разных ключей загрузка должна выполняться параллельно.
При ошибке load() ожидающие горутины тоже должны корректно разблокироваться.
Нельзя использовать внешний пакет singleflight.

load() выполняется ровно один раз на ключ.
Остальные goroutine ждут результат.
load() может быть долгим.
Для разных ключей загрузки параллельны.
Ошибка корректно передаётся всем waiter'ам.
Если load() вызывает panic, ожидающие goroutine не должны зависнуть навсегда.
Сам panic должен продолжить распространяться, а не быть молча проглочен.

99 ожидающих могут уйти по ctx.Done(), не дожидаясь loader;
уход одного waiter'а не должен отменять загрузку для остальных;
если сам loader завершился — все оставшиеся waiter'ы получают его результат;
для разных ключей загрузки независимы
