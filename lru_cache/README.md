### Реализуй LRU Cache:
```
type LRUCache struct {
    // ...
}

func NewLRUCache(capacity int) *LRUCache

func (c *LRUCache) Get(key int) (int, bool)

func (c *LRUCache) Put(key int, value int)
```

Требования:

- Get — O(1) в среднем;
- Put — O(1) в среднем;
- при переполнении удаляется наименее недавно использованный элемент;
- Get существующего элемента делает его самым недавно использованным;
- Put существующего элемента обновляет значение и тоже делает его самым недавно использованным;
capacity >= 1.

Пример:
```
capacity = 2

Put(1, 10)
Put(2, 20)

Get(1)      → 10
Put(3, 30)

Get(2)      → false
Get(3)      → 30
```

Ограничение: нельзя использовать готовую структуру, которая сама реализует LRU. Нужно построить её самостоятельно.

После кода объясни, почему обе операции имеют O(1) и какую роль играют map и двусвязный список.
