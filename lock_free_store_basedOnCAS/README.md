Требования
	IncRequests() и IncErrors() могут одновременно вызываться сотнями goroutine.
	Snapshot() может одновременно вызываться миллионы раз.

	Snapshot() должен быть полностью консистентным:

	Requests и Errors должны относиться к одному состоянию.

	Нельзя вернуть комбинацию значений из разных состояний.

	Snapshot() не должен брать mutex.
	IncRequests() / IncErrors() тоже не должны использовать mutex.
	Нельзя использовать atomic.Value.
	Если несколько goroutine одновременно изменяют состояние, ни один инкремент не должен теряться.
	Stats должен рассматриваться как immutable snapshot после публикации
