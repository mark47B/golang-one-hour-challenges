Семантика
```
rate = 100 означает максимум 100 разрешений в секунду.

burst = 20 означает, что сразу можно пропустить максимум 20 запросов сверх накопленного текущего уровня.
```

Требования:
- Allow() вызывается конкурентно из сотен goroutine.
- Нельзя использовать внешний пакет.
- Нельзя создавать goroutine на каждый вызов Allow().
- При отсутствии токена Allow() должен ждать, а не сразу возвращать ошибку.
- ctx.Done() должен прерывать ожидание.
- После Shutdown() новые вызовы должны получать ErrRateLimiterClosed.
- Нужен корректный shutdown без утечки goroutines.
- Нельзя использовать busy-wait.
- Реализация должна быть потокобезопасной.
- Нужно самому выбрать: mutex + time.Ticker, time.Timer, канал-токены или другую архитектуру.
